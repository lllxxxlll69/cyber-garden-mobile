# Cyber Garden — Android

Android-приложение для визуального создания сценариев проверки учебных Kotlin/Spring Boot проектов. Android 8.0+ (API 26), Java Activity и встроенный интерфейс WebView. Сессия шифруется через Android Keystore.

Возможности: проекты и импорт GitHub, редактор графа, запуск анализаторов, история, PDF-отчёты, привязка Telegram и отправка отчётов. Анализаторы выполняются на сервере.

## Сборка на Windows

Требуются Windows x64 и Python 3.10+:

```powershell
python tools/bootstrap.py
python tools/build.py
```

Bootstrap устанавливает локальные JDK 21 и Android SDK в `.toolchain/` и проверяет контрольные суммы. Можно использовать собственные JAVA_HOME и ANDROID_HOME. Результат: `output/CyberGarden-debug.apk`. Локальный ключ debug-подписи создаётся автоматически и не входит в репозиторий. Для обновления установленного APK сохраняйте свой ключ.

## Подключение

1. Запустите [сервер и Telegram-бота](https://github.com/lllxxxlll69/cyber-garden-telegram-bot).
2. Установите собранный APK на Android.
3. Через USB с включённой отладкой выполните `adb reverse tcp:8787 tcp:8787` и используйте адрес `http://127.0.0.1:8787`. Через Wi-Fi укажите локальный IPv4 сервера и настройте HOST / ALLOWED_HOSTS в серверном `.env`.
4. Зарегистрируйтесь или войдите, создайте учебный проект и запустите сценарий.
5. В профиле получите одноразовый код и отправьте `/login КОД` своему боту в личном чате.

Начальный адрес задаётся в `android/app/src/main/assets/connection.json` и меняется на экране входа. Токен бота задаётся только на сервере. APK, SDK, ключи подписи и пользовательские данные в репозиторий не включены.

Шрифт JetBrains Mono распространяется с лицензией OFL в каталоге assets.
